## 2. Normal Ask Context and Citation Verification

### Investigation of the Reported `citations=20` Result

A rigorous audit of the LangGraph execution flow in `src/advanced_rag/graph/nodes.py` was conducted to understand the distinction between retrieved chunks, prompt context chunks, and returned citations:

```
User Question
      │
      ▼
retrieve_node:
  retriever.retrieve(...) ──► retrieves 20 candidate chunks (state["chunks"])
  context_chunks = chunks[:top_n]  (top_n = settings.rerank_top_n or 5)
  format_context(context_chunks) ──► prompt context contains AT MOST 5 CHUNKS
      │
      ├───► With LLM (Normal Synthesis Mode):
      │       generate_node prompts LLM with exactly 5 numbered context blocks [1]...[5]
      │       state["extractive"] = False
      │       citations_from(state) returns state["context_chunks"] (EXACTLY 5 CITATIONS)
      │
      └───► Without LLM (Extractive Runbook Quoting Mode):
              generate_node executes extractive_answer(state["chunks"])
              state["extractive"] = True
              citations_from(state) returns state["chunks"] (EXACTLY 20 CITATIONS)
```

### Detailed Metric Breakdown

| Metric | With LLM (Default Ask Mode) | Without LLM (Extractive Mode) |
| :--- | :---: | :---: |
| **Chunks Retrieved from Vector Store** | **20 chunks** | **20 chunks** |
| **Chunks Bound to LLM Generation Prompt** | **At most 5 chunks** | **0 (No LLM invoked)** |
| **Chunks Retained in Graph State** | Both `chunks` (20) & `context_chunks` (5) | Both `chunks` (20) & `context_chunks` (5) |
| **Citations Returned to User** | **Exactly 5 citations** | **20 citations** |
| **Meaning of Returned Citations** | Aligned 1-to-1 with prompt citations `[1]...[5]` | Citations for all runbook passages quoted |

### Findings & Reassurance
1. **Prompt Context Ceiling Maintained:** The prompt passed to the LLM in `generate_node` is built from `state["context"] = format_context(context_chunks)`, which is hard-limited to `top_n = settings.rerank_top_n or 5`. The other 15 retrieved candidates **never** enter the LLM prompt.
2. **Citation Mapping Integrity:** When LLM synthesis runs, `citations_from()` returns `state["context_chunks"]`. Citation `[k]` generated by the LLM maps directly to index `k-1` in the response citations list.
3. **What `citations=20` Represented:** The previous report's smoke test passed `force_extractive=True` to test the fallback path without spending LLM API credits. In extractive mode, the system deliberately returns citations for all quoted matching runbook passages (20). When normal LLM synthesis runs, it returns exactly 5 citations.
